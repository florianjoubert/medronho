# Website redesign for Acme Studio

## Goals

Ship a faster, accessible marketing site. Success metric: Lighthouse
performance above 90 on mobile and a bounce rate under 40%.

## Decisions

- Static site generator over a CMS: content changes twice a year.
- System fonts only; the brand survives without a 200 KB webfont.
